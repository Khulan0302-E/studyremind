# Даалгавар (StudyRemind)

Moodle, Microsoft Teams, MyEnglishLab-ын даалгавар, шалгалтыг нэг хуанлид нэгтгэж, хугацаа дуусахаас өмнө сануулга өгдөг вэб апп. Компьютер дээр 3 баганатай хуанли, утсан дээр жагсаалт хэлбэрээр харагдана (`Даалгавар-Хуанли.pdf` дизайны дагуу).

## Ажиллуулах

Node.js 18-аас дээш хувилбар хэрэгтэй. Node 22.5+ бол өгөгдөл SQLite-д, түүнээс хуучин бол JSON файлд хадгалагдана. **`npm install` хийх шаардлагагүй**, frontend аль хэдийн build хийгдсэн байгаа.

```bash
cd ~/Desktop/studyremind
npm run dev          # эсвэл: node server/index.js
```

Хөтчөөс **http://localhost:3000** нээнэ.

- **Windows:** `start.bat` файлыг давхар товшино, эсвэл PowerShell дээр төслийн хавтсанд орж `npm run dev` гэж бичнэ.
- **Mac:** Finder дээр `start.command` файлыг давхар товшино (анх удаа: баруун товч → Open).

**Демо данс:** `namjaa@example.mn` / `password123`

Утасны харагдацыг шалгах: Chrome → DevTools → Toggle device toolbar (⌘⇧M), эсвэл цонхоо 1024 px-ээс нарийн болгоно. Утаснаасаа нээх бол утас, компьютер нэг Wi-Fi-д байхад `http://<компьютерийн-IP>:3000` хаягаар орно.

### Moodle-ийг холбох

Moodle → Хуанли → **Import or export calendars** → **Export calendar** → «All courses» болон «Recent and next 60 days» сонгоод **Get calendar URL** дарна. Гарсан холбоосыг апп-ын «Холболт» хэсэгт буулгана.

### Хичээлийн хуваарийн CSV жишээ

```csv
course,day,start,end,room,teacher,type
Математик I,Даваа,08:00,09:30,3-304,Б.Болд,Лекц
Англи хэл I,Мягмар,11:20,12:50,2-110,S. Smith,Семинар
```

Баганын нэрийг монголоор (`хичээл, гараг, эхлэх, дуусах, танхим, багш, төрөл`) бичиж болно. Гарагийг `Даваа`/`Да`/`Mon`/`1` гэх мэтээр, цагийг `start`, `end` баганад эсвэл `time` баганад `08:00-09:30` хэлбэрээр бичнэ. Тусгаарлагч нь `,` эсвэл `;` байна.

## Хязгаарлалт (демо хувилбар)

- **Teams:** Microsoft Graph API-д сургуулийн admin consent хэрэгтэй тул одоогоор жишээ өгөгдөл ашиглана.
- **Pearson холболт:** Pearson-ы зөвшөөрөл баталгаажаагүй тул товч нь тайлбар мессеж л харуулна (FR-06b).
- **И-мэйл суваг:** тохиргоо хадгалагдах ч SMTP тохируулаагүй тул и-мэйл илгээгдэхгүй. Нууц үг сэргээх холбоос серверийн терминалд хэвлэгдэнэ.
- **Сануулга:** хөтөч (эсвэл суулгасан PWA) нээлттэй үед ирнэ. Хөтөч бүрэн хаалттай үед push мэдэгдэл авахын тулд Web Push (VAPID) серверийг нэмэх шаардлагатай.
- Өгөгдлийг цэвэрлэх бол серверийг зогсоогоод `data/` фолдерыг устгана. Дараагийн асаалтаар демо өгөгдөл дахин үүснэ.
